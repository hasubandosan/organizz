# Дизайн-система LifeOS (v2)

Тёмная палитра `core/styles.css` общая для всех модулей. Модули различаются **логотипом** и **акцентным цветом**.
Всё, что ниже, живёт в `frontend/core` (`styles.css`, `shell.js`, `nav.js`); модули только подключают.

## Акценты модулей
Ставятся атрибутом на `<html data-module="...">` (LifeShell делает это сам; можно прописать в разметке, чтобы не мигало).

| Модуль | `data-module` | Акцент | Логотип |
|---|---|---|---|
| Хаб | `hub` | индиго `#5b6ef5` | 🏠 |
| Проекты | `projects` | бирюзовый `#2fc4b2` | 📋 |
| Питание | `meals` | оранжевый `#f08050` | 🍽 |
| Покупки | `purchases` | лайм `#d4f542` | 🛒 |
| Косплеи | `cosplays` | фиолетовый `#a070f0` | 🎭 |
| Админка | `admin` | красный `#f05060` | 🛠 |

В стилях модуля используйте `var(--accent)`, `var(--accent2)`, а текст на акценте — `var(--on-accent)` (а не `#fff`).

## Единая шапка — `LifeShell`
Подключение (после `core/nav.js`): `<script src="https://organizz-core.pages.dev/shell.js"></script>`.
```js
LifeShell.mount({ module: 'meals', title: 'Рецепты', back: () => Router.back(),
                  replace: '#app-header',                       // необязательно: заменить свою старую шапку
                  actions: [{ icon: '＋', label: 'Новый рецепт', onClick: fn }] });
LifeShell.update({ title: 'Сырники', back: true, actions: [...] });   // при смене экрана
```
Слева «назад» (если задан `back`), логотип и название модуля, справа действия и переключатель модулей (он открывает панель из `nav.js`, плавающая 🧭 при этом скрывается).
`title` — название текущего экрана («/ Сырники»). Свою шапку (`.topbar`, `.hdr`, `#app-header`) в модуле больше не рисуем.

## Адаптивность
- `.lo-page` — контент центрируется, максимум 1100 px.
- `.lo-grid` — карточки сами подбирают число колонок; минимальная ширина — `--col` (по умолчанию 168px): `style="--col:140px"`.
- `.card.compact` — плотная карточка (padding 10px). Картинкам в карточках задавайте фиксированный `aspect-ratio`.
- **Окна** (`.modal-overlay` + `.modal`): на телефоне шторка снизу (до 88% высоты), от 720px — окно по центру (520px; `.modal.lg` — 760px). Кнопки `.modal-footer` прилипают к низу. Полноэкранных окон на широком экране не делаем.

## Правила
- Только тёмная тема, цвета — токены (`--bg*`, `--text*`, `--border*`, `--accent*`), без «своих» палитр.
- Размеры касаний ≥ 36px, отступы мелкие (8–12px), без огромных карточек и пустых полей.
- Один акцентный элемент на экран (главная кнопка), остальное нейтральное.

## Меню аккаунта (в шапке)
LifeShell справа рисует «сэндвич» с аватаром: Аккаунт / Настройки / Выйти. Выход (confirm → очистка token/email → страница входа) уже внутри, модулям свою кнопку «Выйти» делать не надо. Свои экраны: `LifeShell.mount({ onAccount, onSettings })`; скрыть меню: `account: false`.
