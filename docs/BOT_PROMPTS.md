# Готовые задания для ботов (копируй целиком в НОВЫЙ чат Claude)

Каждый бот получает: общий блок + блок своего модуля. Один модуль — один чат.
Мержить по одному: смержил → Netlify задеплоил → проверил → следующий.

## Общий блок (одинаковый для всех)

```
Ты мигрируешь один модуль проекта LifeOS (organizz) с localStorage на общий backend.
Репозиторий (публичный): https://github.com/hasubandosan/organizz.git — склонируй его.
Прочитай по порядку: README.md, docs/ARCHITECTURE.md, docs/NEW_MODULE_HANDOFF.md.
Это инструкция и границы: общие файлы (frontend/core, hub, login, projects, backend, docs)
не трогаешь. Работаешь в ветке module/<имя> от свежего origin/main.
Человек не программист (Windows, VS Code, PowerShell). Экономь токены: без длинных
вступлений и пересказов, сначала короткий план (до 10 строк), потом работа.
Сдаёшь файл патча (git format-patch) + короткий отчёт по пункту «Отчёт человеку».
```

## purchases
```
Твой модуль: purchases («Покупки»). Исходники: legacy-source/purchases/ (index.html — монолит,
index.txt — вероятно заметки). Новая папка: frontend/purchases/. Слаг модуля: 'purchases'.
Особый акцент: ХАБ (frontend/hub) читает покупки для виджета и счётчика — хабу нужны статусы
(например in_stock) и поля. Опиши в отчёте точную структуру записей и коллекции, чтобы
архитектор переключил хаб на DB.getAll('purchases', 'purchases'). Модуль также связан с
core/purchase-quickadd.js и core/shopping-bridge.js — выясни, как они используют данные,
и ничего в них не меняй, только опиши, что нужно поправить.
Покупки могут иметь картинки: используй DB.saveImage/getImage.
```

## cosplays
```
Твой модуль: cosplays («Косплеи»). Исходники: legacy-source/cosplays/index.html (один файл,
маленький). Новая папка: frontend/cosplays/. Слаг модуля: 'cosplays'.
Особый акцент: картинки (референсы, фото) — через DB.saveImage/getImage. Модуль небольшой,
поэтому после миграции пройдись по нему и составь список багов/странностей, которые заметишь
(не чини их без согласования, если они вне миграции).
```
